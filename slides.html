背景 4/4

本研究の核心：熱活性化エアロゲル形成

設計コンセプト
  • セルロースポリマー(HEC, MC, MHEC)が水溶性ゲル骨格を形成
  • コロイダルシリカ粒子(CSP)を均一分散
  • 加熱時に水が発泡 → 多孔構造を作る
  • シリカ粒子が焼結し silica aerogel 層に転換
3つの革新ポイント
  • 水分依存からの脱却：熱でアクティブ化する固体保護層
  • 持続可能な原料：天然由来かつ食品添加物グレード
  • 既存散布インフラと互換：シアシニングで噴霧でき、自己修復性と降伏応力で垂直面に付着・滞留
"Heat-Activated Formation of Silica Aerogels" — 火炎接触をトリガーに、ゲル自身がエアロゲル断熱材へ変態する

メチルセルロース(MC)の熱ゲル化：火炎保護の鍵となる特性

逆熱応答（LCST挙動）
  • MCは冷水（<20°C）に溶解し低粘度溶液を形成
  • 加熱すると下限臨界溶液温度（LCST）を超えてゲル化
  • MCのゲル化開始温度：約 50–60°C（濃度依存）
  • 常温では液体 → 火炎接触で即座にゲル → 流れ落ちを防止

コロイダルシリカ粒子(CSP)と界面活性剤(SDS)

CSP
Colloidal Silica Particles
  • 原液：水中で12 wt%濃度のコロイド分散液
  • 粒子サイズ：数十nmの単分散シリカ
  • 配合濃度：ゲル中 5 wt%
  • 加熱時に焼結 → silica aerogel に変態
SDS（添加剤）
Sodium Dodecyl Sulfate
  • 陰イオン性界面活性剤
  • 役割：発泡を促進し多孔構造を強化
  • 添加濃度：0.1 wt%・0.5 wt% の2水準
  • SEMで気泡サイズ・分布を制御確認
CSPの焼結温度域とセルロースの熱分解温度が重なるため、熱応答が同期して断熱層を形成

HEC+MC vs MHEC：二系統の比較

HEC + MC 混合系
HEC（非熱ゲル化） + MC（熱ゲル化・LCST）
  • HECで常温粘度・付着性を確保
  • MCで加熱時の構造維持を担当
  • より低い n=0.108 → 強い剪断希薄化
  • Time to char ≈ 9–10 min
  • Foaming Index ≈ 2.2–2.6
→ SDSとの相性も良く、発泡構造の最適化に優れる
MHEC 単独系
MHEC（HEC+MC の機能を一分子に統合）
  • ヒドロキシエチル基（HEC由来）とメチル基（MC由来）を同一鎖上に有する
  • 単一ポリマーで同等の粘弾性・熱応答を実現
  • n=0.188（HEC+MC より若干高い）
  • Time to char ≈ 10 min
  • 配合・品質管理が単純化される利点
→ スケールアップ・製造コスト低減に有利
両系統とも市販AquaGel-Kを大幅に上回る性能。HEC+MC系は発泡最適化に、MHEC系は製造簡便性に優れる

実装シナリオ：WEGの展開戦略

WUI住宅の事前保護
  • 山火事シーズン前に建物外壁・屋根に散布
  • ヘリコプター・地上ホース双方で対応可能
  • 乾燥しても保護機能が残る（従来WEGとの差異）
重要インフラの保護
  • 送電塔・変電所・通信基地局
  • 金属構造物にも強固に付着
  • 断電・通信遮断を予防し災害対応を支援
防火線（Fire Break）形成
  • 延焼経路となる植生帯に事前散布
  • Phos-Chek（リン酸系）の環境負荷なし
  • セルロース・シリカは生態系への残留性が低い
既存手法との優位点
vs 水 保護時間 5× 向上
vs AquaGel-K 水蒸発後も継続保護
vs Phos-Chek 土壌・水系への残留なし
散布互換性 既存機材そのまま使用可
航空散布・地上散布ともに対応可能な流動特性（剪断希薄化）が実用化の鍵

研究成果のまとめと展望

RESULT 01
Time to char ~10分
水の約5倍、AquaGel-K比で約40%延長。火炎下の木材保護時間を大幅に拡張
RESULT 02
エアロゲルの自己形成
CSPがheat-activatedで焼結 → 多孔質シリカ層が水蒸発後も継続的に断熱
RESULT 03
既存散布インフラ互換
n = 0.108〜0.188 の剪断希薄化流体。既存のホース・ノズルで噴霧可能
RESULT 04
持続可能な原料
セルロース誘導体は食品グレード、シリカは無害な無機材料。低環境負荷

  • 延焼経路の防火線(fire break)形成
